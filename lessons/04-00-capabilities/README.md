# Chapter 4: Capabilities

In Chapter 3, you gave the chat a place to work: settings, a workspace, file tools and a shell. It can read a project and run its tests. Along the way, you've added entries to `capabilities=[...]`. This chapter explains what those entries do.

By the end, you'll know what a toolset and a hook contribute to the chat, and you'll have watched a run from the inside.

We'll start by giving the chat a toolset of its own. Then we'll look inside a run: a run is a loop, and you can attach code to named hooks in it. That code only watches, and your chat keeps a record of what it did on your machine.

That's as far as the chapter goes for now. Hooks that change a run, and capabilities of your own, may follow in later lessons.

You'll keep working on the **same chat application**, and each lesson gives you a way to see what changed. A few lessons are mostly new ideas, and one is mostly connecting work. Each says which it is at the start.
